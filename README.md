# 初中生错题本工作台

面向福州初中生的错题收集与复习工作台，纯静态响应式 Web App（手机 / iPad / 笔记本通用）。
线上地址：https://cjwx-bot.github.io/cuoti-workbench/

## 功能
- 错题库：拍照/相册选图录入、增删改查、难度/错因筛选、关键词搜索
- 题干 HTML 富文本：支持加粗/斜体/上下标/标红，可直接粘贴带格式的题目；存储同时保留富文本与纯文本（供搜索）
- 云端 OCR：OCR.space 识别（照片会上传到第三方，需知情同意）；Key 不写入源码，可自填并仅存本机；默认官方公共测试 key（有速率限制）
- 公共题库：从仓库只读 questions.json 加载示例题，一键加入本机错题库（不含学生数据）
- 信息同步展示：列表卡片与重练页同步呈现题干/错答/错因/难度/正确答案解析
- 错因统计：错因/难度/掌握度分布、高频知识点
- 组卷重练：先隐藏答案后揭晓，标记掌握自动回写
- 数据导入导出：JSON 备份，浏览器本地存储

## 隐私说明
- 学生错题数据默认存本机浏览器，不上传服务器，不含姓名/班级等个人信息
- 云端 OCR 为可选功能，使用时照片会上传到 OCR.space
- 题干富文本做白名单清洗，剥离脚本与危险属性
- 公共题库 questions.json 为通用示例题，不含任何学生个人信息
