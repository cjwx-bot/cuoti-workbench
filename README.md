# 初中生错题本工作台

面向福州初中生的错题收集与复习工作台，纯静态响应式 Web App（手机 / iPad / 笔记本通用）。
线上地址：https://cjwx-bot.github.io/cuoti-workbench/

## 功能
- 错题库：拍照/相册选图录入、增删改查、学科/错因筛选、关键词搜索
- 双引擎 OCR：本地识别（Tesseract，照片不外传）+ 云端识别（OCR.space，识别率更高但照片上传到第三方，需知情同意）
- 公共题库：从仓库只读 questions.json 加载示例题，一键加入本机错题库（不含学生数据）
- 错因统计：学科/错因/掌握度分布、高频知识点
- 组卷重练：先隐藏答案后揭晓，标记掌握自动回写
- 数据导入导出：JSON 备份，浏览器本地存储

## 隐私说明
- 学生错题数据默认存本机浏览器，不上传服务器，不含姓名/班级等个人信息
- 本地 OCR 完全在浏览器内完成；云端 OCR 为可选功能，使用时照片会上传到 OCR.space
- 公共题库 questions.json 为通用示例题，不含任何学生个人信息
- 云端 OCR 的 API Key 不写入源码，用户可自填并仅存本机；默认使用官方公共测试 key（有速率限制）
